# AetherDrop 2.1.3

基于 [zheznanohana/nekodrop v2.1.3](https://github.com/zheznanohana/nekodrop)，保留原作者与上游贡献者署名及开源许可。

- 跟进累计上游更新，保留雷达、发送、Wi-Fi、Apple ID 与仅限联系人设置。
- 保留 AetherDrop 品牌、微软雅黑、同卡片接收状态转换、0.8 秒实时速率与完成后打开所在位置。
- 统一钢蓝与中性灰配色，提供浅色、深色及跟随系统外观；主题色选择栏移除。
- 精简托盘右键菜单，修复首尾高亮动画与边缘文字高亮；主窗口支持任务栏、居中打开与拖动。
- 接收卡片移除关闭 X；中断显示“接收已停止”与暗红色逐笔 X 动画。
- 设置保存无修改时禁用；保存成功完整停留 1 秒，保留进入与退出动画。
- 安装包包含 x64 客户端与服务、Intel / Realtek / MediaTek 后端、固件、Python 引擎、Apple ID 辅助组件及运行环境。
