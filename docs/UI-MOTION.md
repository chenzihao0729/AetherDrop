# UI 与动效统一

本次把 stageshow 的层级、对齐、稳定文本和有因果的动效原则应用到真实 WPF／WinForms 界面；沿用软件自己的组件，不另建网页演示或引入 React。

## 实施约定

- 选择项使用整行浅色高亮与右侧对勾，不在文字前绘制单选圆圈。文字左边保持相同起点，右侧对勾预留固定位置。
- 按钮与选择行只渐变背景、按压反馈和标记；文字不做缩放，不使用父级位图效果。
- 悬停约 120 ms，按压约 70 ms，释放约 160 ms；快速反向从当前状态继续。选中标记只做短距离进入，不改变文本布局。
- 设置切换只过渡内容区域，外框、标题和底部按钮保持固定。浮层从触发处附近轻移进入，关闭保留系统淡出。
- Windows 减少动画设置优先：关闭动画时立即呈现最终状态。
- 保留主窗口居中与拖动、托盘轮廓和箭头、现有接收卡片状态替换、0.8 秒速率与完成停留 4 秒。

## 验证方式

原生控件通过离线交互测试和深浅色截图检查选中、悬停、切换与最终静止状态。覆盖主窗口、设置各页、Wi-Fi、发送、Apple ID、托盘及接收卡片。网页演示的 film／gate 不适用于原生 WPF，本次不生成伪 UI 替代实际程序测试。截图与过程输出保留在忽略的 build 目录，不进入安装包。


## 本轮复核

- 深浅色下检查接收选项、快捷设置、设置各页、Wi-Fi、发送与 Apple ID 窗口；接收卡片保留既有位置与尺寸。
- 检查选中标记、悬停与快速反向切换的中间状态，以及最终不残留变换的状态；模式页首次打开即正确显示当前选择。
- 原生主菜单／二级菜单使用右侧对勾。修正 ToolStrip 缩窄后保留旧项目宽度导致对勾画到窗口外的问题，并增加像素范围检查。
- UI 调试流程、微软雅黑常规／真实粗体、窗口居中与拖动、托盘点击与卡片流程通过。未修改正式用户设置，未改变传输协议或重新打包 EXE。
- 本轮未执行网页 film／gate，也未用额外的网页动画代替原生程序验证；系统关闭动画的分支已保留，未改动 Windows 动画开关。


## 窗口边缘与点击范围

主界面与设置采用 12 DIP 的抗锯齿透明轮廓，内容单独裁切到内侧圆角；不使用整数区域剪裁来放大系统圆角。标题栏保持可拖动，设置窗口的边缘调整尺寸仍由命中测试处理。右上角按钮提供完整的 32 × 32 点击区，悬停只改变图标颜色，不显示方形底色。就绪状态控件移除焦点和普通描边。相关检查覆盖按钮四角／中心命中、窗口拖动、快捷设置对齐与内容裁切。


## 接收控制与 Apple ID 关联

仅限联系人和所有人统一放在快捷设置的“隔空投送接收”下方，左上角不再单独打开接收菜单。顶部开关是接收总开关；范围列表不再提供重复的“接收关闭”。关闭时保留上次范围，重新开启时恢复；关闭期间修改范围不会自动开启接收。

仅限联系人必须同时满足已保存的 Apple ID 功能开关和本地身份；所有人排在第一，仅限联系人常驻第二；缺少条件时灰显不可选择。快捷菜单移除 Apple ID 设置链接。应用内部调用仍验证身份，不改变当前有效接收范围。设置保存、身份登录／导入／移除后会通知快捷设置和其他已打开的设置窗口；未保存的设置开关仍遵守保存／取消流程。单纯开关接收不会覆盖设置中尚未保存的范围选择。


主窗口失去焦点保持显示，由右上角关闭按钮关闭。设置保存不再重复注册 Explorer 菜单与快捷方式；启动项仅在选项变化时更新。保存后在窗口中央显示矩形成功提示，对勾描边动画 360ms，约 1.8 秒后收起；减少动画模式直接显示完整对勾。接收配置变化所需的引擎退出异步等待，不阻塞界面绘制。


保存提示改为 144 × 144 DIP 正方形，使用与直线边缘曲率连续的矢量圆角，不透明主题背景，仅对勾描边播放动画。保存按钮比较实际可保存的草稿与已保存快照，修改启用、还原禁用、保存后建立新快照；外部接收设置同步不覆盖其他未保存内容。紧凑选项（跟随系统、自动、台式机、笔记本）只保留高亮，其他选择列表继续显示对勾。设置标题栏不再绘制底部分隔线。主窗口显示独立任务栏入口及 AetherDrop 图标，隐藏时一同撤下。

本轮验证可运行 `UiDebug.Smoke --settings-only`，覆盖设置脏状态、保存提示、紧凑选项、主窗口与接收菜单；不会进入独立的传输模拟回归。

保存提示的背景与前景拆为独立轨道：背景从中心展开并收拢，文字只做轻移与显现，对勾错峰描绘。完整结果停留约两秒后退出。保持不透明背景、无文字缩放；连续保存可以中断旧退出并续接当前表面。实际时序及检查见 `REHEARSAL.md`。
