## 合入内容

- 引擎等待 awdl0 首次就绪时不再被客户端误重启，保留首次发现的设备。
- DMA 连续内存不足时使用 5、10、20、30 秒退避，避免密集重启。
- Intel 蓝牙均衡共存始终开启，移除旧开关；保留定制设置布局。
- 蓝牙信标被系统中止时记录原因并重试，支持只读 DryRun 验证。
- Realtek 后端报告对端 5GHz 信道；自动跟随模式额外统计 awdld 数据活动。
- 新增 MediaTek MT7902 后端、固件及许可、手动型号、安装检测与报告支持。
- 卸载支持部分卸载目录重试、客户端注销超时，以及手动卸载后的快捷方式
  与卸载注册项清理；继续保护卸载器进程，保留现有错误日志和等待关闭行为。
- 更新兼容性文档、版本号和上游历史记录。

## 保留的定制

AetherDrop 名称、项目及文件引用、图标、中文 README 与原作者署名；
Microsoft YaHei、深浅色、窗口大小与布局、托盘及传输动画、4 秒完成停留；
不显示文件名、打开所在位置按钮、0.8 秒速率刷新；现代/传统右键菜单二选一；
C:\Program Files\AetherDrop 默认安装目录；
自包含运行库、明确的运行文件清单、先移除 Inno Setup 再卸载应用的定制顺序。
安装包输出到 build 根目录，不创建修复包子目录或 ZIP 安装包。

后续按用户要求，信道恢复上游 0.1.38 原逻辑。Supervisor.cs 与 Config.cs 采用标签源码，仅替换品牌名称；旧 FixedChannel 字段不再生效。

随后针对实测视频问题增加会话保护：日志显示 80MB 视频已接受、尚未上传时
遇到信道切换。现在自动跟随会等待客户端的确认/准备/传输会话结束；不恢复固定
信道或额外候选稳定等待。上传准备期限由 30 秒改为 180 秒，详见
[信道与会话保护](CHANNEL-STABILITY.md)。
