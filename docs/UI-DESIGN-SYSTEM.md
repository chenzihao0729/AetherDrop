# AetherDrop 桌面界面布局与视觉规范

本轮先确定层级、间距和断点，再调整现有 WPF / Windows Forms 页面。保留现有控件、文字、设置、传输逻辑和交互动效；不使用新的网页界面代替桌面程序。

## 方向与层级

面向在 Windows 与 Apple 设备之间收发文件的用户。附近设备雷达是主界面唯一的视觉重心；文件操作、接收记录和保存位置为辅助信息。设置页以“设置名称—解释—操作”组织，不增加装饰性标题、数字、图标或卡片。

```text
主界面                     设置与辅助窗口
品牌                操作   标题                    关闭
附近设备            状态   分类导航（设置）
雷达                       设置名称／说明          控件
文件操作                   分组内容
接收记录                   可滚动内容
保存位置            操作   保存反馈            操作按钮
```

复核时保留雷达、蓝色、深浅色及既有通知模板这些产品特征。没有把所有页面改为同一种大型卡片，也没有统一放大整个界面。设置、菜单、通知各自保留适合其任务的密度。

## 色彩

| 基础角色 | 色值 |
|---|---|
| 浅色背景 | `#F3F5F9` |
| 浅色表面 | `#FFFFFF` |
| 浅色正文 | `#1C2024` |
| 深色背景 | `#202226` |
| 深色浮层 | `#303338` |
| 产品蓝 | `#007AFF` |

深色内容卡片为 `#2B2E33`，悬停表面为 `#34383F`；文字采用 `#F2F4F7` / `#B6BEC8` / `#A0A9B5` 三层。浅色次级文字为 `#5C656E`，辅助文字为 `#6C737A`。常规表面不透明，分隔线只区分实际分组。浮层独立于正文绘制阴影，不把文本一起栅格化。

用户指定的主题色、跟随系统和多彩模式继续优先。接收卡片上的既有蓝色插画、按钮与状态色保留。原先自绘浮层偏蓝的深灰调整为与主页面一致的中性灰；原生右键菜单沿用同一语义色板。

## 字体与尺寸

- 保留 Microsoft YaHei，使用真实的 Normal / Bold 字重。
- 正文 13 DIP，说明 12 DIP、行高 18 DIP，分组标题 14 DIP，重点反馈 15–17 DIP。
- 小型菜单、状态标记和通知使用既有紧凑字号，保持固定模板。托盘品牌标题 17 DIP。
- 不通过 Viewbox 或父级整体缩放调整文字。布局尺寸是 DIP，由 Windows DPI 和布局舍入适配显示器。
- 既有鼠标悬停、选中高亮、右侧对勾与键盘反馈继续按组件原有规则使用；已移除的焦点外框和四个紧凑选项对勾不恢复。

## 间距与几何

以 4 DIP 为基本步长，使用 4 / 8 / 12 / 16 / 24：

| 用途 | 规范 |
|---|---|
| 页面外侧、常规卡片内侧 | 16 DIP |
| 分组间距 | 12 DIP |
| 独立区域间距 | 24 DIP |
| 标签与说明间距 | 4 DIP |
| 同行操作按钮间距 | 8 DIP |
| 常规按钮与输入框最低高度 | 32 DIP |
| 辅助窗口标题栏 | 48 DIP |
| 主窗口标题栏 | 保留 52 DIP |
| 设置、发送、登录底部操作区 | 56 DIP |
| 主窗口保存位置区 | 52 DIP |
| 自绘主窗口、设置窗口外圆角 | 保留 12 DIP |

标题栏文字与页面内容左对齐，关闭按钮保留完整的 32 × 32 命中区域；标题栏不加底部分隔线。普通内容卡片为 8 DIP 圆角，交互面采用原有的 6–8 DIP。系统绘制的辅助窗口外缘保留系统平滑圆角。

紧凑浮层是有意保留的例外：托盘 244 × 208、接收卡片 302 × 142、卡片内距 15、接收操作单倍宽 72 / 双倍宽 144、按钮高 28。接收卡片标题／中间文字／底部槽位不变，完成、失败继续在同一卡片替换内容。

## 桌面断点

| 条件 | 布局行为 |
|---|---|
| 设置窗口宽度 ≥ 500 DIP | 较长的一般设置名称在左、控件在右 |
| 设置窗口宽度 < 500 DIP | 语言、主题色、本机图标改为名称在上、原控件在下；保持原实例、值、选择和保存状态 |
| 导航宽度不足 | 原分类按钮换行，不缩小文字、不删除分类 |
| 主窗口高度 ≥ 640 DIP | 雷达区域 408 DIP |
| 主窗口高度 < 640 DIP | 雷达区域 344 DIP，设备节点与文字保持原尺寸 |
| 内容超出可用高度 | 正文滚动，标题与底部操作留在窗口内 |

这是桌面应用的工作区适配，不添加手机网页断点。设置窗口最小宽度仍为 460，Wi-Fi 为 380，发送为 400；不修改这些窗口的业务入口。

## 页面覆盖

- 主页面、快捷接收菜单：统一页面边距、主次区域间距及表面；保留接收开关联动。
- 设置五个分类：统一卡片内距、分类导航、说明行高和底部操作区；新增窄窗排列规则。
- 发送、Wi-Fi、Apple ID 登录与验证码：统一标题栏、关闭按钮、操作区和输入控件度量。
- 托盘、原生主菜单及二级菜单、邀请／传输／完成／中断卡片：沿用现有组件和模板，统一表面与文字色；托盘信息行整理为 40 DIP 步长。
- UI 调试入口：沿用原组件，整理为 24 DIP 外侧间距和既有基础色。

## 验证方式

`UiDebug.Smoke --layout-only` 使用内存设置和模拟数据，检查原有交互、标题按钮命中、正常／紧凑窗口、五个设置页、中英文导航、发送、Wi-Fi、登录／验证码与浮层。截图在忽略的 `build/layout-system-dark` 和 `build/layout-system-light`，不进入安装包。

额外检查原有浮层固定模板和原生菜单的排版、选中提示与平滑圆角。没有修改无线协议、引擎、安装器、更新版本或正式设置，也不把视觉检查描述为实际设备传输验证。


## 精简托盘右键菜单

右键菜单只保留“打开 AetherDrop / Wi-Fi / 设置 / 生成诊断报告 / 退出”五项，移除接收开关与联网方式子菜单，相关功能保留在主界面和设置中。菜单文字不带省略号。保持微软雅黑、统一行高、12 DIP 文字边距、8 DIP 上下留白；两条分隔线区分打开、工具和退出。现有高亮移动和系统平滑圆角不变。原生菜单移除不再需要的尾部标记保留空间，沿用现有组件。深浅色 Typography.Smoke 验证通过，截图在 `build/tray-menu-five-*`。
