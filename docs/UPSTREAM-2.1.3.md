# 上游 v2.1.3 同步记录

## 合入内容

- 保留 2.1.0 的主面板、雷达／列表设备视图、发送与 Wi-Fi 界面、分组选项设置、快捷键和强调色。

## 保留的 AetherDrop 定制

- 品牌、图标、中文 README、微软雅黑、深浅色模式和无文字悬停提示。
- 即时单击托盘弹窗、双击主界面、点击空白关闭、折叠托盘定位与自定义右键菜单。
- 原有接收／进度／完成／中断卡片及动画；同一张卡片替换内容、不显示文件名、0.8 秒实时速率、完成停留 4 秒、打开位置后立即关闭。
- 设置每次居中；新界面的文件列表与历史同样隐藏文件名。
- 默认接收目录及服务、安装路径、迁移逻辑保持 AetherDrop；保留安装卸载保护、Inno 卸载等待、右键菜单去重及安装文件白名单。
- 信道继续采用上游自动跟随逻辑，保留传输会话与协商阶段保护。保留大视频准备期、缓冲和原始媒体能力补丁。

合并时补齐全部新增界面翻译并修正深色状态文字，修复接收开关读取旧设置造成的状态回跳，并将上游接收请求状态与定制浮窗／雷达关联，完成、拒绝和中断时同步清理。
