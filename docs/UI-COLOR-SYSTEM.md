# AetherDrop 配色规范

本轮只调整颜色，覆盖现有 WPF 页面、自绘托盘／接收卡片及 Windows Forms 右键菜单。色值集中在 `app/client/UiColors.cs`，`Theme.cs` 与 `Palette.cs` 分别提供现有资源名和自绘组件兼容映射。

| 角色 | 浅色 | 深色 |
|---|---|---|
| 唯一主色 | `#315F8C` | `#8FB4D8` |
| 主色上的文字 | `#FFFFFF` | `#17212B` |
| 背景 | `#F5F5F4` | `#202122` |
| 内容表面 | `#FFFFFF` | `#2A2C2E` |
| 浮层 | `#FFFFFF` | `#303234` |
| 悬停表面 | `#ECEEED` | `#36393B` |
| 选中底色 | `#E6EDF3` | `#303D49` |
| 正文 | `#242729` | `#EFF0EF` |
| 说明 | `#565C60` | `#BCC0C2` |
| 辅助文字 | `#646B70` | `#A4ABAF` |
| 边框 | `#D9DCDA` | `#45494B` |
| 强边框 | `#B7BEBC` | `#646C70` |
| 成功 | `#397052` | `#91B89C` |
| 警告 | `#85602B` | `#CEAF7C` |
| 错误 | `#A34A45` | `#D99A94` |

- 钢蓝降低了原亮蓝的饱和度，仅引导操作、选择与进度。深浅色使用同一色相，分别保证背景上的可读性。
- 中性色表面不再偏蓝；不增加渐变、霓虹色或装饰性状态色。
- 成功、警告、错误仅承担状态含义。拒绝等非错误状态保留中性灰。
- 按用户要求不更改结构，原有四个主题选项及保存键保留，全部解析到同一主色；旧系统主题色和多彩偏好也不再引入第二种主色。原始品牌 logo 图片不改色。
- 深色接收按钮的文字由白色改为深墨色，使浅钢蓝底上的文字达到足够对比度。

验证：`UiDebug.Smoke --colors-only` 检查深浅色正文、说明、辅助文字、主色文字在五种表面上的对比度，以及语义状态与主按钮文字；检查组合均达到 4.5:1。`--layout-only` 深浅色检查通过，截图在忽略的 `build/color-system-*`。Typography.Smoke 深浅色检查通过，菜单截图在 `build/color-menu-*`。

本轮与修改前本地快照对照，XAML 模板、布局度量、字体、圆角、阴影与动效未修改。没有新建网页；网站专用浏览器 gate 不适用于原生 WPF / Forms，本轮不宣称网页 gate 通过。未重新打包或发布安装器，未修改正式用户配置。


## 外观选择

主题色色块整栏已删除。在常规设置的启动／快捷键组内新增“外观”：浅色、深色、跟随系统，默认跟随系统，沿用分段高亮控件和保存／取消流程。`Settings.Appearance` 单独持久化，不改变旧 accent 的兼容读取。

保存后更新所有窗口主题资源、自绘卡片的活动画刷、开关颜色和原生菜单；不关闭或重建正在接收的卡片，不重启引擎。系统模式监听 Windows 用户外观偏好变化，显式浅／深色不被系统覆盖。`--appearance-only` 验证三种选择、保存状态、已打开卡片的原窗口句柄与实时颜色更新，且正式设置文件和注册项保持不变。操作截图位于 `build/appearance-live`。
